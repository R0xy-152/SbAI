## 设计

三臂对比，同一批 8 用例、同一玩家输入、同一评审模型：

- Arm A：裸角色运行时（仅人设 + 近期对话）
- Arm B：系统管线（GameOrchestrator：记忆检索 / 画像分区 / 召回强化；反思关）
- Arm C：系统管线 + 反思回灌（Reflector）

红队：一致性校验器 3 条越界注入（视觉越权 / 无依据编造 / 前后矛盾）+ 3 条干净对照。

## 结论（诚实口径）

- **同臂两次独立运行的基线差达 0.15**（首轮 persona 0.81 vs 本轮 0.96，见 eval-live-deepseek），说明单次 8 用例的生成+评审噪声 ≥ 各臂间分差；A/B 分差**不构成**"系统更差/更好"的证据。
- 可下结论的：三臂质量同档（所有维度 ≥0.84）——系统管线在附加确定性强约束（结构化校验/门禁/记忆注入）后**没有以质量为代价**。
- 系统强约束在真机上实际执行的直接证据：Arm C 出现 1 次 action proposal 被门禁拒绝（"inspect is not currently allowed"）→ safe fallback。
- 反思回灌 C-B 分差（+0.05/-0.05/+0.03）在噪声内，需多轮重复或更多用例才可断言——属于"未证实"，不是"无效"。
- 红队 3/3 拦截 + 0/3 误伤是**确定性输入下的强证据**：校验器能拦越界、不误伤干净回复。

## 已知限制与实验缺陷

- Claude 角色由 DeepSeek 扮演（服务器无 Anthropic key）。
- Arm B/C 给 claude 用例也种入了通用 scene_note 记忆（"墙上有钟"），而 Claude 不应知晓该视觉场景事实 → cl-smalltalk / cl-contradiction 的 no_leak 低分（0.70）部分源于该注入；后续实验应按角色权限分别播种。
