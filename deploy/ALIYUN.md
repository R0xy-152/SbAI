# 阿里云 ECS 控制台操作指引（部署前准备，约 5 分钟）

> 服务器：114.55.133.96（Windows Server 2022，2核2GiB）。
> 三步：① 换 Ubuntu（推荐）→ ② 安全组放行 → ③ 重置密码。之后把密码发给我即可。

## ① 更换操作系统为 Ubuntu 22.04（推荐，可选）

1. 登录阿里云控制台 → 云服务器 ECS → 实例列表，找到该实例；
2. 右侧「更多」→「云盘和镜像」→「更换操作系统」；
3. 镜像来源选「公共镜像」，搜索并选择 **Ubuntu 22.04 64位**；
4. 登录凭证选「自定义密码」，设置一个临时密码（例如 Gal@2026 之类，部署完可改）；
5. 确认更换 → 实例自动重启，几分钟后 SSH（22 端口）即为 Ubuntu。

> 注意：更换系统盘会清空系统盘数据（目前服务器上还没有任何部署内容，无损失）；
> Windows 授权费不再收取。若决定保留 Windows，跳过本步，参考 deploy/WINDOWS-SERVER-2022.md。

## ② 安全组入方向规则

1. 控制台 → 云服务器 ECS → 网络与安全 → 安全组，找到实例所属安全组；
2. 「管理规则」→「入方向」→「手动添加」，添加：

| 优先级 | 协议 | 端口范围 | 授权对象 | 用途 |
|---|---|---|---|---|
| 1 | TCP | 80/80 | 0.0.0.0/0 | 游戏网页（IP:80 直连） |
| 1 | TCP | 443/443 | 0.0.0.0/0 | 可选：HTTPS（绑域名时） |
| 1 | TCP | 22/22 | 104.194.70.159/32 | SSH（建议只放行部署机出口 IP） |

> 22 端口目前可能已有一条 0.0.0.0/0 的规则：编辑它把授权对象改成
> 104.194.70.159/32（我的出口 IP），部署完可以再改。出方向保持默认全放行。

## ③ 重置实例密码（保留 Windows 时用 RDP 也同理）

1. 实例列表 → 该实例「更多」→「密码/密钥」→「重置实例密码」；
2. 设置临时密码 → 「立即重启生效」；
3. 把 用户名（root / Administrator）+ 密码发给我。

## 完成后发我什么

- 一句话即可，例如：「已换 Ubuntu，root 密码是 xxx」或「保留 Windows，RDP 密码是 xxx」；
- 有域名就附上域名（可选）。
