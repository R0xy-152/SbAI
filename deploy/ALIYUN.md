# 阿里云 ECS 控制台操作指引（部署前准备，约 5 分钟）

> 服务器：114.55.133.96（Windows Server 2022，2核2GiB）。
> 三步：① 换 Ubuntu（推荐）→ ② 安全组放行 → ③ 重置密码。之后把密码发给我即可。

## ① 更换操作系统为 Ubuntu 22.04（推荐，可选）

1. 登录阿里云控制台 → 云服务器 ECS → 实例列表，找到该实例；
2. 右侧「更多」→「云盘和镜像」→「更换操作系统」；
3. 镜像来源选「公共镜像」，搜索并选择 **Ubuntu 22.04 64位**；
4. 登录凭证选「自定义密码」，设置一个临时强密码（例如 `ChangeMe@2026` 之类，部署完立即改掉）；
5. 确认更换 → 实例自动重启，几分钟后 SSH（22 端口）即为 Ubuntu。

> 注意：更换系统盘会清空系统盘数据（目前服务器上还没有任何部署内容，无损失）；
> Windows 授权费不再收取。若决定保留 Windows，跳过本步，参考 deploy/WINDOWS-SERVER-2022.md。

## ② 安全组入方向规则

1. 控制台 → 云服务器 ECS → 网络与安全 → 安全组，找到实例所属安全组；
2. 「管理规则」→「入方向」→「手动添加」，添加：

| 优先级 | 协议 | 端口范围 | 授权对象 | 用途 |
|---|---|---|---|---|
| 1 | TCP | 80/80 | 0.0.0.0/0 | 游戏网页（IP:80 直连） |
| 1 | TCP | 443/443 | 0.0.0.0/0 | 可选：HTTPS（绑域名时） |
| 1 | TCP | 22/22 | 104.194.70.159/32 | SSH（建议只放行部署机出口 IP） |

> 22 端口目前可能已有一条 0.0.0.0/0 的规则：编辑它把授权对象改成
> 104.194.70.159/32（我的出口 IP），部署完可以再改。出方向保持默认全放行。

## ③ 重置实例密码（保留 Windows 时用 RDP 也同理）

1. 实例列表 → 该实例「更多」→「密码/密钥」→「重置实例密码」；
2. 设置临时密码 → 「立即重启生效」；
3. 把 用户名（root / Administrator）+ 密码发给我。

## ④ 域名 ICP 备案（sbai.xin 上线 HTTPS 前置条件，免费，7-20 天）

> 服务器在中国大陆，域名解析过去必须先通过 ICP 备案，否则访问会被拦截。
> **备案期间不要给域名添加解析（A 记录）**——管局初审会检查网站可访问性，
> 域名保持无解析即可（现在的 nip.io / IP 地址访问不受影响，照常玩）。

1. 阿里云控制台搜索「备案」→ 进入备案控制台（beian.aliyun.com，首次会引导验证）；
2. 「开始备案」→ 主体信息：**性质选「个人」**，按实名信息填写；
3. 网站信息：域名填 `sbai.xin`；
   - **网站名称避开「游戏平台 / 网络游戏」等需要前置审批的字眼**（个人备案审核会卡），
     起个中性名称即可，例如「SBAI 个人作品站」，简介写个人作品展示/学习交流；
4. 服务器信息：选「阿里云」→ 当前账号下 114.55.133.96 这台 ECS；
   - ⚠️ 备案要求 ECS 计费时长 **≥ 3 个月**（按量付费不支持备案）——若你是按月购买，
     需要在控制台把续费时长补到 3 个月以上再提交；
5. 按提示做**人脸核验**（阿里云 App 扫码）；
6. 提交后：阿里云初审 1-2 天 → 各省管局审核 7-20 天 → 通过后收到备案号短信。

**备案通过后**（两步，然后交给我）：

1. 云解析 DNS（阿里云控制台 → 域名 → sbai.xin → 解析设置）添加 A 记录：
   主机记录 `@` → 记录值 `114.55.133.96`（www 加不加都行，建议加一条 `www`）；
2. 告诉我「备案过了」，我把 Caddyfile 加一行 `sbai.xin`（自动 HTTPS 证书），
   2 分钟生效，之后 `https://sbai.xin/` 即为正式地址，nip.io 保留备用。

## 完成后发我什么

- 一句话即可，例如：「已换 Ubuntu，root 密码是 xxx」或「保留 Windows，RDP 密码是 xxx」；
- 有域名就附上域名（可选）。
