## 1. 问题清单与优先级（轻→重，后不破前）

| # | 问题 | 定位（现状） | 优先级 | 依赖 |
|---|---|---|---|---|

| P4 | 继续按钮命中区小 | GameDialog.vue #sendButton（translate-x-full、px-2 py-2） | 轻 | 无 |
| P5 | 缺睁眼转场 | 现仅 LoadingTransition 猫爪揭幕 | 中（自包含新组件） | 无 |

## 2. 各步设计

### P1 情绪标签中文映射
- frontend-vue/src/adapters/lingchat-compat.ts：新增 EMOTION_ZH 映射（见 §0），showCharacterEmotion 返回中文标签。
- 更新受影响单测断言（GameDialog.spec 等）。

### P2 思考中动画省略号
- GameDialog.vue：thinking 占位符改为「····」；输入区叠加 CSS 动画省略号（4 个点逐点亮起循环，仅 thinking 状态显示）。
- 兼容层 showCharacterThinkLine / toGameRole.thinkMessage 同步为「····」保持一致性（当前未被其它组件显示）。
- 更新 GameDialog.spec 占位符断言。

### P3 标题背景响应式分档
- TitleView.vue 保留清晰层与模糊兜底层；默认使用 3:2 近景图 cover，`min-aspect-ratio: 19/10` 切换 21:9 扩展图。
- `min-aspect-ratio: 49/20` 的极端超宽屏将清晰层改为完整高度，剩余横向空间由同图模糊层填充。
- 视差容器只左右超扫 12px，覆盖最大 6px 位移；禁止继续使用 120% 宽造成额外裁切。
- 重拍标题屏视觉基线；docs/15 §4.1 校准。

### P4 继续按钮命中区扩大（按钮不动）
- #sendButton 位置与视觉外观不动，扩大 padding（向下/右/上方扩展，向左仅极小扩展避免压到 textarea 右侧输入区），并保证 z 序在对话框内容之上。
- 实现后截图确认与上方选项条（P7 前仍存在）、系统菜单等不重合；E2E locator 不变。

### P5 睁眼转场
- 新增 frontend-vue/src/components/effects/EyeOpenTransition.vue：全屏黑幕 + 上下眼睑分离露出画面，约 1s；pointer-events: none（不挡点击）；prefers-reduced-motion 跳过。
- stores/settings.ts 新增 eyeOpenTransitionEnabled（默认 true，向后兼容）+ SettingsView 开关；tests/visual/fixtures.ts freezeAnimations 注入 false；settings.spec 补默认值断言。
- GameView 挂载即播：新游戏路径排在 LoadingTransition 完成之后；读档/会话恢复路径直接播。

### P6 台词按换行分段
- GameView：主台词按 
 切段（去空段），推进队列统一为「台词段 → script_sequence 行 → 解锁输入」；onDialogProceed 依序推进，每段替换式重打。
- 恢复历史 / 读档路径保持现状：最后一句即时整段显示，不重播、不分段。
- 更新受影响 E2E 等待逻辑。

### P7 开局选项窗口 + 线索窗口
- 新增 OptionWindow.vue（lingchat 式竖排选项窗口：选项 + 「继续对话」关闭项）与 ClueWindow.vue（线索窗口：证据标题 + 描述 + 关闭）。
- 触发：AI 台词全部播完后点继续，若 options 非空 → 弹 OptionWindow（窗口期间输入保持锁定，关闭后解锁，D4 自由输入不受限）。
- investigate 选项点击 → 执行既有步骤端点（自动调查+拓印）→ 成功后经 GET /api/game/evidence 取证据详情 → ClueWindow 展示。
- 气泡条在此期间隐藏 investigate 项（单一入口）；docs/14 D6 增补修订。

### P8 全部选项窗口化 + 气泡条退役
- OptionWindow 覆盖全部 kind（chat_routing 粘性高亮、deduction 提示、evidence_present / private_interview 仍走 SubActionPanel、recovery / narrative）。
- OptionsPanel 退役（GameView 移除引用）；feedback 改为系统台词行展示（与 deduction 提示一致）；routeLabel 由窗口内高亮承担。
- 「桌上的纸」气泡随之消失（问题 6）。
- E2E ch1-options-t3/t4 按窗口更新；游戏内相关视觉基线重拍；docs/14 D6 / §2.2 / §3 全面修订。
