# 功能 05：单独审问权小游戏

## 1. 目标

Player不能随意隔离任何AI。必须通过短小游戏证明当前角色存在值得单独调查的信息缺口，获得：

```text
PRIVATE_INTERVIEW_RIGHT
```

## 2. 设计原则

- 30~90秒
- 无API实时依赖
- 玩家亲自判断
- 使用已有Evidence / Claim
- 不另造完全独立的系统
- 正确结果确定性

底层统一为：**Evidence Manipulation Framework**。

## 3. Claude挑战：信息断层

Player选择Claude Claim + Evidence，建立Knowledge Gap。

目标：找出Claude明确知道、但公开证词未解释来源的信息。

成功：`PRIVATE_INTERVIEW_CLAUDE = unlocked`。

## 4. GPT挑战：遗漏事实

GPT公开总结列出若干事实。Player从Evidence池中找出她刻意未纳入总结的关键事实。

目标不是证明她撒谎，而是证明她在选择性组织Evidence。

## 5. 豆包挑战：观察 vs 解释

把豆包说法拆成：

```text
Observed Fact
+
Doubao Interpretation
```

例如：

```text
“Claude说话了”
↓
屏幕显示CLAUDE
+
豆包认为=Claude说话
```

## 6. DeepSeek

第一章默认拥有DeepSeek私聊权限，无需挑战。

## 7. 私审模式

- 其他角色不自动获得私审内容
- Character Context切换Private Disclosure Rules
- 退出后记录`private_interview_completed = true`

## 8. 错误处理

选错不扣资源、不Game Over、允许重试。避免无脑穷举可限制一次提交数量或增加明确逻辑反馈。

## 9. 验收标准

1. 每个角色私审权单独持久化。
2. 结果由Backend判定。
3. 不依赖LLM响应速度。
4. 私聊内容不自动泄露给其他角色。
5. 三个挑战体现各自信息问题。
6. 错误可重试。
7. 私审后复用自然语言询问系统。
