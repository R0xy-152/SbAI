# 2. 项目基本信息

## 2.1 游戏名称

**《完蛋，我被AI娘包围了》**

---

## 2.2 项目类型

本项目是一款：

**AI + Galgame + 对话式悬疑解谜游戏。**

AI不是附加聊天功能，而是核心交互组成部分。

---

## 2.3 核心产品定义

玩家在游戏中的主要体验是：

> 通过与角色进行自然语言对话，获取信息、建立关系、推进剧情并完成解谜。

游戏不以传统 Galgame 的固定选项作为核心输入方式。

---

# 3. 核心交互边界

## 3.1 玩家唯一主动输入

玩家唯一主动操作方式为：

**与角色进行自然语言对话。**

玩家不通过传统功能按钮直接执行剧情行为。

---

## 3.2 不采用的核心玩法

当前项目不设计以下玩法作为玩家主动交互方式：

- 战斗
- 自由地图移动
- 物品栏
- 装备
- 技能
- 数值养成
- 传统任务系统
- 传统 A / B / C 剧情选项
- 点击地图选择下一场景

如果未来出现相关元素，也不能取代“自然语言对话”作为核心交互方式。

---

# 4. 主线方向

## 4.1 主线必须明确存在

本项目不是开放式 AI 陪聊产品。

游戏必须存在：

- 明确的主线
- 明确的谜题
- 明确的剧情推进
- 明确的阶段性目标
- 明确的结局

AI自由对话必须运行在主线游戏框架之内。

---

## 4.2 主线类型

当前已确定：

**主线采用悬疑 / 解谜结构。**

核心循环为：

```text
对话
→ 获得信息
→ 发现异常或矛盾
→ 继续询问 / 验证
→ 推进调查
→ 解锁后续剧情
```

---

# 5. 开场固定设定

以下内容已经冻结。

游戏开始时：

1. Player 在陌生环境中醒来。
2. DeepSeek 与 Player 被绑在一起。
3. Player 与 DeepSeek 需要合作寻找逃离方法。
4. Claude 是将 Player 与 DeepSeek 置于当前困境中的主要责任者。
5. Claude 属于主线反派阵营。

---

# 6. 正式角色范围（仅声明，不定义）

当前正式 AI 拟人角色共 **4 名**：

- DeepSeek
- 豆包
- ChatGPT
- Claude

另有：

- Player

---

# 7. 角色系统约束（不含人设）

本文件仅定义系统层约束：

## 7.1 AI驱动规则

- 部分角色使用 LLM
- 部分角色使用确定性 Script Engine
- 是否接入 AI 由角色运行系统决定

---

## 7.2 角色职责分层

系统层面角色功能划分：

- 主线推进角色
- 陪伴角色
- 吉祥物角色
- 反派角色

具体人格与行为规则不在本文件定义。

---

# 8. 场景范围

当前项目采用：

**固定场景背景**

第一版正式游戏原则上：

**场景数量不超过 5 个**

---

# 9. 视觉表现范围

游戏采用标准 Galgame 式视觉结构，包括：

- 固定背景
- 角色立绘
- 对话框
- 角色名称
- 玩家文本输入
- 基础菜单

允许基础动画：

- 抖动
- 位移
- 淡入 / 淡出
- 表情切换
- 简单缩放

---

## 9.1 后期视觉演出方向（可扩展）

允许：

- UI Glitch
- UI 破裂
- UI 消失
- 屏幕异常
- Meta UI 演出
- 第四面墙破坏

---

# 10. AI 使用边界

当前项目不是：

> 所有角色必须 AI 驱动

---

## 已确定：

### 使用生成式 AI

- DeepSeek
- ChatGPT
- Claude

### 不使用生成式 AI

- 豆包

---

# 11. 当前开发阶段

项目当前处于：

# 轻量技术验证阶段

目标：

> 验证核心技术路线是否可支撑完整产品

---

# 12. 当前明确非目标

不包含：

- 3D游戏
- 开放世界
- 战斗系统
- 复杂经济系统
- 装备 / 技能系统
- AI生成立绘 / CG
- Live2D强依赖
- 语音强依赖
- MMO
- 商业化系统
- 大规模分支剧情树
