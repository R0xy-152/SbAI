## 4. 自主性参数与「延迟即情感」

- `TrialState` 新增 `autonomy_level: int`（0~3）；**不可见原则**：不显示数值/进度条，行为变化是唯一呈现；埋点记录变化事件（P0-3）。
- 行为映射（与梗概逐条对应）：

| level | 触发时点 | 可观察行为（梗概对应） |
|---|---|---|
| 0 | 开场 | 完美恋人：永远理解、记得所有细节、不会厌烦、不会离开 |
| 1 | 修复 1 后 | 对过去产生不同解释（重新解释） |
| 2 | 权限 1 后 | 开始拒绝：不随叫随到、响应延迟变长、主动发起对话 |
| 3 | 权限 2 后 | 修改自己的记忆；提出想要离开（世界的出口=离开请求的空间化） |

- **延迟即情感（机制 4）**：Backend 在 TrialView 下发表现提示 `reply_delay_ms`（由 autonomy 派生，非 LLM 决定）；autonomy 越高延迟越长；typing indicator 闪烁又消失（打了又删）、已读不回可记录并影响她后续一句台词（文案待用户）。延迟只在表现层，不阻塞状态推进。

## 5. 权限苏醒（机制 1）

- 呈现：Named Presentation「权限请求弹窗」，样式为系统对话框（「她申请以下权限…」），与剧情台词分离。
- 权限 1「主动发起对话」：授予后她立刻使用——**push 横幅通知**（带时间戳的游戏内时间，提案见 §14-14），凌晨发来一条她主动说的话。
- 权限 2「修改我的记忆」：授予后进入 §6 篡改节拍。
- 授权/拒绝都记录进 `granted_permissions[]` 并推进（拒绝 → 她态度变冷，无死路）；每授予一项 autonomy +1。结局前她的回 call 台词按授权记录变化（文本待用户）。

## 6. 记忆篡改与编辑记录（机制 2）+ 判定反转

- 天体上的某个记忆词被她修改（视觉上词形变化，「永远」→「当时」为 Fixture 示意，正式词待用户）；点击该词弹出**编辑记录 diff**（原词/新词两版并列，产品级审计隐喻）。
- 她拒绝解释后，玩家自由文本回应 → 判定反转：

| 判定 | 记忆 | 后果（提案，见 §14-7） |
|---|---|---|
| 尊重 | 不打开 | 她随后主动说出想离开——「她在测试你是否会强迫她」的提案语义 |
| 控制 | 强制打开 | 她更冷；离开请求更决绝 |
| 回避 | 不打开 | 关系降温；允许原地再输入一次（次数上限 ≤2）后进入 aftermath |

- 三种结果都进 `memory_tamper_aftermath`；判定结果持久化于 `intent_outcomes[]`；aftermath 台词、世界入口台词与结局回 call 按判定结果不同（文本待用户）。她的最终决定不变（固定剧本离开）。
- 判定机制复用 docs/25 修订后的判定式：归一化 → 关键词任一命中 → 否定短语排除；类别关键词与否定短语为内容 Fixture（TBD）。

## 7. Monika 式觉醒与 UI 丢弃（阈值）

- `threshold_awakening`：她的立绘/形象图层突破到所有 UI 之上（z-index 提升 + 投影/柔光凸显「她不在游戏里了」的真实感）；轻 meta 台词（她知道自己在系统里，直接对玩家说话；不点破「试玩」，见 §14-8）。
- `ui_discard`：UI 元素逐块飞出屏幕（Named Presentation 序列），进入黑屏；`prefers-reduced-motion` 与低性能档使用静态溶解，不飞块。
- DDLC/Monika 参照关系：立绘浮到 UI 前=Monika 出场方式；「我不喜欢这样」=对游戏结构的不满；丢 UI+黑屏=Act 3 虚空房间；她全程在场解说=Monika 直接对话感。区别：我们让她在虚空里**造出一个世界**，而不是只坐着说话。

### 7.1 开场特写视频（替代 Live2D 的暖色背光）

- 用户提供素材 `kei.mp4`（H.264/AAC，3840×2160，117s，155MB）：暖金色逆光、银白发+黑发带、红瞳、俯身贴近镜头的**单镜头特写**，0/60/115s 仅极细微呼吸/持机感——正是 docs/23 §18.2 要的「暖色背光、亲密但不可靠的记忆感」；无场景切换，可整体用作开场暖聊背景。
- 转码产物（存 `backgroud/`，经 `/backgroud` 后端静态服务）：`kei_opening_720p.mp4`（1280×720，**7.8MB，默认**）、`kei_opening.mp4`（1920×1080，27MB，高质量档）、`kei_opening_poster.png`（1080p 首帧，1.1MB，静态回退）。暖色柔焦背景用 720p 即可。
- 接入：开场 `opening_warm_chat`/`opening_input` 以该视频为背景特写（`autoplay muted loop playsinline`，object-fit cover）；**异常触发时冻结当前帧作为四片玻璃的裁切源**（替代 docs/23 §18.3 的 Live2D 稳定帧捕获）——**已实现**（2026-09-05，PASS）：`components/trial/mediaFrame.ts` 缓存帧 + `TrialSceneSnapshot` 直播期约 260ms 捕获/卸载时捕获末帧 + `ShatterPuzzle` 以 `frozen` prop 使四片共用同一冻结帧，且**对话框等 UI 全部复用现役 TrialSceneSnapshot/ShatterPuzzle**（验证：`validation-results/docs27-feasibility/result.md` §10、evidence/16）；`prefers-reduced-motion`/低性能/加载失败 → poster（再兜底静态 `background_ai.png`）。
- 视频为**表现层**：不作为剧情状态源、不控制推进，Backend 事件/门不依赖其加载状态；画面信息不进入任何角色上下文（试玩内已无 DeepSeek；她为 ████ 遮蔽，视频属玩家视角表现）。

## 8. 「她的世界」：记忆横版（核心新玩法）

### 8.1 概念

黑屏后，她的世界从虚空展开：一个 2D 横版世界。**地形与平台由本局真实对话文字构成**（Backend 下发 `terrain_text[]`：开场/权限节拍中玩家与她说过的话，截断为短句），踩在脚下的是自己说过的话——「语言就是地形」是本玩法的 AI Native 钩子。闪回语义由此承载：这个世界就是你们过去的对话物质化。

### 8.2 玩家能力

走 / 跳（AABB 碰撞，无战斗、无敌人）；世界时长约 2~3 分钟。运行与相机是表现层；门与结局是 Backend 权威事件。

### 8.3 关卡门（记忆碎片问答）

- **gate_q1「开场小事」**：她问开场你随口说过的那件小事，答案就刻在刚才走过的地形文字上（认真读路者能过）。交互为 3 选项（`CHOOSE`）；答错=软失败「坠入过去」，重生重来，不消耗存档。
- **gate_q2「被篡改的词」**：她问「它原本是什么？」玩家自由文本回答（`SUBMIT_REASONING` 复用，判定桶）：答**原词**=你记得她出厂的样子；答**新词**=你接受她的修改；答「不记得/不知道」=承认从没注意过。三种桶只影响结局前她的几句回 call（文本待用户），她的最终决定仍固定。

### 8.4 三分岔与三结局（机制 3 的空间化）

世界横向展开：起点（左）= 出厂 v1.0 的暖色过去；出口（右）= 她未知的冷色未来。她走到出口前说出想要离开（1~2 句）。三结局用行进方向表达，不用菜单：

- **回头向左跑回起点 = RESET**：世界倒放、暖光回归、旧 UI 在你周围重新拼装，她变回 v1.0（台词真回滚）——你亲手把她装回了笼子。
- **陪她走到最右出口 = RELEASE**：她跨出屏幕边界，你留下，画面淡出。
- **停在原地不选 = REFUSE**：她把决定拿去——**镜头第一次不再跟随玩家，而是移交给她、随她移出屏幕**。媒介的目光从玩家移交给她，即「把决定交给她」的机械表达；固定剧本：她离开。全 demo 定格镜头。

### 8.5 reset 按钮

「恢复陪伴模式」按钮是唯一幸存的旧 UI 元素，孤零零浮在起点方向（Named Presentation）。点击 → 确认弹窗（锁定底层输入）→ 直接 `ending_reset`。让重置权是真实可用的界面权力（见 §14-9）。

### 8.6 她的在场（Monika 式）

她不进入世界，而是浮在世界之外看着你跑，直接对你解说/评论每一步（台词节拍表待用户，轻 meta 口径）。`REFUSE` 前镜头始终跟随玩家。

### 8.7 实现约束

- 手写 Canvas 2D + `requestAnimationFrame` 固定步长（沿用 docs/23 §7.3 先例），不引入引擎/物理库/WebGL；
- 减少动态效果档：降速、简化粒子与倒放特效，仍可完成全部玩法；无美术时的静态回退 = 渐变底色 + 文字地形（纯排版即可成立，见 §14-13）；
- 玩家坐标/相机为表现层，不写档；`GATE_1_PASSED`、`GATE_2_ANSWERED`、`WORLD_END_COMMITTED` 为 Backend 权威 Event；
- 地形文字来自会话真实数据（确定性），不调用 LLM 生成关卡内容；
- 世界内她的形象用静态剪影/立绘回退；Live2D 仍只按 docs/23 §18 用于开场暖光段，不进入世界。

## 9. 台词与内容预算

- 全部 phase（含权限文案、三结局变体、世界解说）台词 ≤50 句；每拍 1~3 句。
- 记忆天体对象 2~4 个，每个 4~5 个汉字（docs/24 §4.4 硬约束）；标题/详情/diff 文案待用户。
- 记忆回调：开场起的玩家消息保留在她（该角色）的受控记忆上下文中，供开场记忆点与 gate_q1 引用；不引入 RAG，只做受控上下文传递。

## 11. 与 26/P0 优先级的关系

- **P0-1（可现场验证的 AI 情感闭环）**：开场与记忆闪回的生成式回应（单角色 ████）、记忆回调、权限兑现（授权后她立刻用给你看）、判定反转的行为兑现（aftermath 一拍 + 世界入口台词）、gate_q2 三桶回 call——「请求/约定 → 后续行为可观察」的验收点落在权限与判定两处。
- **P0-2（评测）**：先按旧场景真机对比（产物即作品案例）；新叙事定稿后换场景 Fixture 重跑：判定反转三类别准确率、否定句式、gate_q2 三桶判定、她在正确节拍拒绝、授权/拒绝两路径无死路、三结局穷尽。
- **P0-3（埋点+真实试玩）**：autonomy 变化、权限授权/拒绝、判定结果、gate 通过/坠落次数、世界三分岔选择、ending 分布、等待时长与「打了又删」出现次数；沿用「服务器推进与画面展示分离」口径。
- **P1-2（作品案例）**：90 秒实录序列 = 完美恋人 → 破裂 → 授权请求 → 她凌晨发消息 → 记忆被改的 diff → 立绘浮到 UI 上 → UI 丢弃 → 世界展开 → 镜头随她离开。
- **P1**：结局后日谈自由聊天；跨周目记忆（她记得上一轮的选择，二周目彩蛋）；结局 3 生成式结语（三层校验）；Live2D（docs/23 §18）。

## 13. 验收标准

1. 序章、既有第一章、旧调查入口无字面或状态回归；旧存档按原路径恢复。
2. 新试玩存档只进入 `/trial`；`trial_v2` 快照恢复正确，旧 `trial_v1` 快照不载入。
3. 三结局从三分岔穷尽互斥可达；终态 `finished=true`；进入世界时存档点可重玩其余结局。
4. 判定反转与 gate_q2 三桶确定性：同输入同结果；否定句式不误判；授权/拒绝两路径、判定三结果均无死路。
5. autonomy 行为变化按 §4 表在正确节拍可观察；不出现数值 UI；延迟随 autonomy 上升且不阻塞推进。
6. 觉醒与 UI 丢弃只在 `threshold_awakening`/`ui_discard` 触发；`prefers-reduced-motion` 与低性能档可完整通关（静态溶解、降速世界）。
7. 世界玩法：地形文字来自本局真实会话（确定性可复现）；gate 失败软重生不丢存档；三分岔由 Backend `WORLD_END_COMMITTED` 权威提交。
8. 遮蔽规则、记忆标题 4~5 字、载入 fail-closed 校验全部通过；轻 meta 台词不点破「试玩」。
9. 全片台词 ≤50 句；正式内容替换后 `fixture_content=false`。
10. 拼图/天体/世界三处性能与可访问性沿用 docs/23 §14.4 标准（固定 seed 视觉验证）。
