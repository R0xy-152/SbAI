## 1. 实现结构

### 后端（backend/app/script/）

- story_content.py —— 07 剧本内容数据：14 个场景、全部字面对白（含 Player 台词）、3 个选项点（每个选项携带专属回应台词）、缺台词场景的系统叙述行。**内容与 Runtime 分离**，载入时 fail closed 校验（坏 speaker / emotion / 空台词 / 嵌套选项 / 重复 id 一律拒绝启动）。
- story_runtime.py —— StoryRuntime：链表式节点图（台词节点带 next 指针；选项分支末句 next 跳过选项节点直指合并主线，分支台词不进主线推进序列），每会话整数游标，current / advance / choose / snapshot / restore。**不触碰 NarrativeState / Evidence / Investigation 等既有权威状态**，与既有 Script DSL（docs/12）并行、互不依赖。

### 后端接线

- PersistedSession 新增 story_cursor 字段（向后兼容：旧快照缺省 None = 故事未开始），随既有 Session / Save 快照链路持久化——刷新、读档、自动存档自然携带剧本进度。
- GameOrchestrator 新增 story_current / story_advance / story_choose：游标移动 → 台词写会话历史（History 面板可用）→ 持久化 → 场景边界自动存档。
- SaveSnapshotService.auto_save_story：故事模式场景边界 / 选项提交即 checkpoint，直接覆写 AUTO slot（故事模式没有 Narrative checkpoint 机）。
- app/api/story.py 三个端点：

| 端点 | 语义 |
|---|---|
| GET /api/story/current?session_id= | 刷新 / 读档恢复当前展示节点（不移动游标） |
| POST /api/story/advance {session_id?, player_id?} | 「继续」：下一节点；首次调用即开始故事 |
| POST /api/story/choose {session_id, option_id, player_id?} | 提交 A/B/C 选项，返回该选项第一句台词 |

### 前端（frontend-vue/）

- src/api/story.ts —— 三个端点的类型与封装。
- src/views/StoryView.vue —— 剧本播放器（新路由 /story）：无输入框，GameDialog 恒为 responding 态（「▼」= 继续），选项点弹 StoryChoiceWindow，结局显示 StoryEnding；复用系统菜单 / 存档 / 读档 / 历史 / 加载演出 / 睁眼转场。
- src/components/game/standard/StoryChoiceWindow.vue —— A/B/C 选项窗口（必须选择，无「继续对话」关闭项）。
- src/components/game/standard/StoryEnding.vue —— 「第一章 完 / To Be Continued」结局画面。
- 路由：/story 新增；Title「开始游戏 / 继续游戏」与 LoadView「读取存档」均指向 /story；旧 GameView（/game，调查玩法）保留但无 UI 入口。

## 2. 与既有系统的关系（边界）

- **旧调查玩法不删除**：/api/chat、/api/game/*、Script DSL、Evidence / Deduction / Private Interview / Recovery / Security Review 全部原样保留，后端测试全绿（426 passed）。
- **故事模式不写 Narrative State**：故事会话的 narrative 部分保持默认（phase=opening / scene=binding_room），与旧存档校验白名单兼容。
- **旧存档兼容**：读取旧调查玩法存档时 story_cursor 缺省 → 故事从第一个节点开始（有限制、不崩溃）。

## 3. 已知限制（快速上线接受）

1. 内容来自评审阶段文稿，后续以正式剧本替换 story_content.py 即可；
2. 无音效、无差分立绘表情（沿用单图 + 滤镜）、豆包为占位图；
3. 缺台词场景为系统叙述行概括（新写占位文本）；
4. 07 中 SC02 的自由聊天段未实现（AI 停用），只保留两段推荐固定桥段；
5. 自动存档粒度 = 场景边界 + 选项提交（约 17 次 / 完整流程）。
