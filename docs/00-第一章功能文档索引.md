## 跨功能原则

### Backend 权威

以下内容不得由 LLM 决定：

- 是否获得证据
- 证据内容
- 角色实际知道什么
- 角色是否撒谎
- 矛盾是否成立
- 玩家推论是否正确
- 私审权是否解锁
- Recovery 小游戏结果
- 管理员权限归属
- AI 是否被删除
- 结局分支

### LLM 负责

- 理解玩家自然语言
- 把自然语言映射成有限 Intent / Claim
- 按角色人设自然回应
- 在已知事实范围内解释、追问、质疑
- 根据关系状态调整语气和主动程度

### MVP原则

第一章优先验证：

> 调查 → 询问 → 证据 → 矛盾 → 私审 → 危机协作 → 权限 → 最终信任选择

不在第一版扩展复杂通用推理引擎。
