# 6. Act 4：信任冲突

## 叙事功能

从“寻找事实”转向“选择相信谁”。

- 解决方案。

## 核心冲突

```

```

# 11. Demo叙事约束

## 必须保持

- 玩家先喜欢角色，再面对伦理问题；
- 信息逐层公开；
- 真相不能早于情感建立；
- 选择必须对应价值观。

---

## 禁止

- 第一章直接解释全部世界观；
- AI角色只作为信息工具；
- 选择只影响剧情分支，不影响主题表达；
- 使用单纯“坏AI”制造冲突。
