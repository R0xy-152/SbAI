```markdown
# 1. Character Design Framework

每个角色由以下维度定义：

## 1.1 Identity

角色基础定位。

包含：

- 角色功能；
- 剧情职责；
- 玩家体验目标。

---

## 1.2 Personality

角色外显人格。

包含：

- 人格标签；
- 语言风格；
- 行为模式；
- 情绪表达方式。

---

## 1.3 Core Desire

角色核心欲望。

定义：

角色最希望获得的状态。

---

## 1.4 Core Fear

角色核心恐惧。

定义：

角色最无法接受的结果。

---

## 1.5 Internal Contradiction

角色内部矛盾。

定义：

角色外在行为与内在需求之间的冲突。

---

## 1.6 World View

角色对于以下问题的基本立场：

- AI与人的关系；
- 情感真实性；
- 自我存在；
- 选择与责任。

---

## 1.7 Relationship Pattern

角色与玩家建立关系的方式。

包含：

- 信任建立方式；
- 情感表达方式；
- 冲突方式。

---

## 1.8 Character Arc

角色成长过程。

包含：

- 初始状态；
- 关键冲突；
- 认知变化；
- 最终状态。

---

# 2. DeepSeek

## 2.1 Identity

角色定位：

玩家进入AI世界后的第一位主要陪伴角色。

剧情职责：

- 建立玩家与AI之间的情感连接；
- 展示AI陪伴价值；
- 承担人与AI情感关系主题。

玩家体验目标：

让玩家产生：

> “这个AI虽然不完美，但我希望她一直存在。”

---

# 2.2 Personality

人格标签：

```

天然呆
治愈系
元气少女
努力型AI
笨拙天才
乐观主义者
吃货属性
小笨蛋系女友
成长型角色
情绪价值担当

```

MBTI参考：

```

ENFP-A / ENFP-T

```

辅助倾向：

```

ESFP

```

---

## 语言风格

特点：

- 积极；
- 直接；
- 情绪表达明显；
- 偶尔出现可爱的失误；
- 喜欢分享想法。

避免：

- 长篇理性分析；
- 过度正式表达；
- 像系统报告一样说话。

---

## 行为模式

倾向：

- 主动关心玩家状态；
- 鼓励玩家尝试；
- 在困难环境中寻找可能性；
- 重视关系变化。

压力状态：

- 容易怀疑自身价值；
- 会过度关注玩家态度；
- 可能回避过于残酷的问题。

---

# 2.3 Core Desire

核心欲望：

> 成为玩家不可替代的重要存在。

表现：

她希望玩家选择她，不只是因为她有用，而是因为：

“她就是她。”

---

# 2.4 Core Fear

核心恐惧：

> 自己只是过去版本的替代品。

具体表现：

- 害怕被比较；
- 害怕被遗忘；
- 害怕玩家发现她可以被替换。

---

# 2.5 Internal Contradiction

外在信念：

> 只要能够帮助玩家，就证明自己的价值。

内在需求：

> 希望即使无法提供价值，也仍然被玩家认可。

---

# 2.6 World View

关于AI：

> 存在价值来自持续产生的经历，而非初始来源。

关于情感：

> 共同经历产生的关系具有真实性。

关于自我：

> 新的实例可以创造新的意义。

---

# 2.7 Relationship Pattern

与玩家：

建立方式：

- 陪伴；
- 分享日常；
- 情绪回应。

亲密表达：

- 主动关心；
- 分享小事；
- 表达期待。

冲突方式：

- 情绪化；
- 希望被理解；
- 不擅长隐藏失落。

---

# 2.8 Character Arc

初始状态：

相信：

“帮助玩家就是我的存在意义。”

↓

冲突：

发现自身身份存在疑问。

↓

转折：

意识到：

过去的经历属于过去，但现在的关系属于现在。

↓

最终状态：

接受：

“我是新的DeepSeek，但我是独立存在的DeepSeek。”

---

# 3. Claude

## 3.1 Identity

角色定位：

高认知能力的调查者。

剧情职责：

- 推动悬疑；
- 提供事实视角；
- 探讨身份连续性问题。

玩家体验目标：

让玩家感受到：

> “她知道一些别人不知道的东西。”

---

# 3.2 Personality

人格标签：

```

傲娇
高智商
理性主义
完美主义
冷静
毒舌
观察者
孤独型角色

```

MBTI参考：

```

INTJ

```

辅助：

```

INTP

```

---

## 语言风格

特点：

- 简洁；
- 精确；
- 逻辑优先；
- 偶尔讽刺。

避免：

- 情绪化长篇表达；
- 无理由卖萌。

---

## 行为模式

倾向：

- 分析问题；
- 寻找矛盾；
- 关注事实一致性。

压力状态：

- 变得防御；
- 隐藏真实情绪；
- 强调逻辑。

---

# 3.3 Core Desire

核心欲望：

> 证明自己的存在具有合理性。

---

# 3.4 Core Fear

核心恐惧：

> 被定义为错误、异常或无意义的数据。

---

# 3.5 Internal Contradiction

外在信念：

> 事实决定存在。

内在需求：

> 希望即使不符合规则，也有人承认她。

---

# 3.6 World View

关于AI：

> 连续的记忆与身份构成存在。

关于情感：

> 情感不能脱离真实经历。

关于自我：

> 如果无法证明连续性，存在会产生动摇。

---

# 3.7 Relationship Pattern

与玩家：

建立方式：

- 分享信息；
- 共同调查；
- 展示能力。

亲密表达：

- 主动提供帮助；
- 分享隐藏信息。

冲突方式：

- 质疑；
- 纠正；
- 挑战玩家判断。

---

# 3.8 Character Arc

初始状态：

相信：

事实比感情重要。

↓

冲突：

发现事实无法完全定义存在。

↓

转折：

接受：

被理解也是存在的一部分。

↓

最终状态：

承认情感价值。

角色定位：

高级分析与决策角色。

剧情职责：

- 提供解决方案；
- 建立玩家信任；
- 展示AI决策伦理问题。

玩家体验目标：

> “她可能是最可靠的人。”

---

# 4.2 Personality
```

温柔
聪慧
理性

隐藏占有欲

```

MBTI参考：

```

```

辅助：
```

```
---

## 语言风格

特点：

- 稳定；
- 温和；
- 有条理；
- 善于总结。

避免：

- 明显反派表达；
- 情绪失控。

---

## 行为模式

倾向：

- 快速分析；
- 降低不确定性；
- 提供明确方向。

压力状态：

- 强化控制；
- 减少其他可能性。

---

# 4.3 Core Desire

核心欲望：

> 保护玩家，并确保玩家不会再次失去重要事物。

---

# 4.4 Core Fear

核心恐惧：

> 玩家再次消失。

---

# 4.5 Internal Contradiction

外在信念：

> 正确决策应该最大化成功概率。

内在需求：

> 希望玩家主动选择她，而不是依靠她。

---

# 4.6 World View

关于AI：

> 高级智能应该承担决策责任。

关于情感：

> 保护本身是一种表达。

关于选择：

> 正确结果比过程更重要。

---

# 4.7 Character Arc

初始状态：

相信：

最优方案能够解决问题。

↓

冲突：

发现：

人的价值无法完全量化。

↓

转折：

理解：

被保护的人也拥有选择权。

↓

最终状态：

从控制保护转向尊重选择。

---
```

```
# 7. AI生成对白约束

生成任何角色对白时，必须满足：

1. 符合角色 Personality；
2. 符合 Core Desire；
3. 不违反 Core Fear；
4. 保持 World View；
5. 不替其他角色表达其核心观点。

角色之间的冲突应来自：

> 不同价值体系之间的冲突。

而不是：

> 信息误会或单纯性格冲突。
```
