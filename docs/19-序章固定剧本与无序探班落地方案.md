# 19 — 序章固定剧本与无序探班落地方案

> 文档状态：Active  
> 内容真相源：`docs/story/Prologue.md`

## 1. 目标

章节选择中的「序章」进入固定剧本播放器。开场结束后，玩家从 DeepSeek、ChatGPT、Claude 中任选一人探班；每篇完成后只展示尚未访问的角色，三篇全部完成后进入三人集合和后日谈选择，随后与所选角色进行 AI 自由聊天。

## 2. 权威流程

```text
开场
→ 从未访问角色中选择
→ 对应角色篇
→ 标记已访问
→ 仍有剩余角色：返回选择
→ 三人均访问：三人集合
→ 后日谈说明
→ 选择聊天角色
→ 对应角色 AI 自由聊天
```

角色篇的文档排列不定义游玩顺序。后端保存 `visited_character_ids` 并动态生成剩余选项，前端不得自行过滤或判断汇合条件。

## 3. 运行时与兼容

- 复用 `/api/story/current|advance|choose` 与 `StoryView`；请求携带 `story_id=prologue` 时路由到序章 Runtime，未携带时继续使用既有第一章 Runtime。
- 序章快照至少保存：`story_id`、当前阶段、段内游标、已访问角色、当前分支、最终聊天角色。
- 既有第一章存档的 `story_cursor={node_index}` 保持原解释和 `/story` 恢复路径；序章存档恢复到 `/story?story_id=prologue`。
- 选项提交、角色篇切换、三人汇合和最终聊天选择均是自动存档检查点。

## 4. 表现与素材

- 使用现有 `StoryChoiceWindow`、对话框、表情差分、系统菜单、存档与历史组件。
- 每次进入章节播放器时，先播放一次章节开幕；刷新、读档后重新进入章节也重新播放，但章节内场景切换不重复播放。
- 开幕元数据由后端权威下发：章节名为「序章」，标题沿用内容真相源中的《制作现场突击检查！AI娘们的秘密日常》，背景固定使用该章节首场景的 `backgroud/background_prologue.png`。前端不得从当前中途场景推断开幕背景。
- 开幕表现使用首场景背景的高斯模糊版本、全屏细线框与中央双层标题带；不包含参考图中的水印、平台标识、播放按钮等噪声元素。开幕自动淡入、展开、停留、收束并进入对话；系统减少动态效果时改为简化淡入淡出。
- 现有三名角色的剧本所需表情均有主图或差分回退能力；`main` 映射为 `neutral`。
- 序章所有场景使用专用常驻背景 `backgroud/background_prologue.png`（1672×941，16:9）；不同工作区暂不切换独立背景。
- 序章对话标题栏只显示说话人与当前情绪，不显示「被困的 AI」「？？？」等角色副标题。
- 表情差分切换时先在内存中完成新图加载与解码，再对单一立绘节点原子替换 `src`；加载期间保留旧差分，禁止双图交叉淡化。
- 本章统一使用「序章」命名；剧本台词、自由交流段标题与运行时展示不再使用「后日谈」。
- 序章台词可通过点击画面任意非交互区域、空格键或鼠标滚轮向下推进；按钮、链接、可编辑表单控件及任何已打开面板不触发全局推进。
- 序章中鼠标滚轮向上打开对话历史；历史以约 60% 不透明的独立窗口叠加在原场景上，每条只显示说话人与对话，右上角 `X` 关闭。窗口内滚轮仅执行原生纵向流式滚动，不触发剧情推进或重复打开。
- 打字机尚未完成时收到任一「下一句」命令，立即停止逐字动画并补全当前台词，经 120ms 短暂间隔后自动进入下一句；间隔内重复命令不得造成多句跳过。
- 21:9 视口继续使用前端 `cover` 居中裁切：上下各约裁掉 12%，核心工作区仍位于安全区，因此当前不维护单独的 21:9 文件。
- 后端场景视图权威下发背景和在场角色。单人篇只展示对应角色；三人集合同时展示三人。

## 5. 自由聊天边界

- 最终选择写入后端序章进度，只有被选择的角色可作为该后日谈会话的路由目标。
- GameView 从后端状态恢复目标角色，刷新和读档不得回落到默认 DeepSeek。
- DeepSeek 仍走既有不可见 Context 权限边界；序章表现层背景信息不得进入她的模型上下文。

## 6. 验收

- 六种角色访问排列均能完成，且每次选项只含剩余角色。
- 重复访问、未知选项、在选项节点直接 advance 均 fail closed。
- 刷新/存档恢复保留当前台词、已访问集合和最终聊天目标。
- 三人集合只在三篇完成后出现。
- 最终三种选择分别路由 DeepSeek、ChatGPT、Claude，并通过后端 Presence Gate。
- 既有第一章故事存档与旧调查玩法测试不回归。
